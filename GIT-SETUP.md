# Git setup and submission checklist

1. Create a GitHub/GitLab repository named `pm-plan-misorakmony`.
2. Extract these files into the repository folder.
3. Replace `Mi Sorakmony` placeholders.
4. Open Git Bash in the repository folder and run:
   ```bash
   git init
   git checkout -b lab-01
   git add -A
   git commit -m "Lab-01: setup"
   ```
5. Review each file and commit task by task if your lecturer expects separate commits. Do not commit secrets.
6. Push the branch and open a merge request titled `Lab-01 – [Your name]`.
7. Preview `lab01/process-groups.md` in VS Code with Mermaid support and check both CSV files in Calc or Excel.
8. Confirm all placeholders are replaced and that your lecturer accepts the budget assumptions.

The SaaS price is an assumption of USD 15 per lecturer/month, as allowed by the brief if real education pricing cannot be verified. Replace it with a verified vendor price and citation if required.
