## Grey zones

**Initiative 7: Add multi-node scaling to Realtime Quiz.** This is a project if authorised as a separate upgrade with its own scope, budget, team and completion date. It could be an operation if treated as routine maintenance. The sponsor's authorisation, budget and acceptance criteria would settle the classification.

**Initiative 9: Write and publish the annual IT report.** This is a project if it requires unique analysis, a defined deliverable and formal acceptance by the dean. It could be an operation if it is a standard repeated reporting procedure. The scope, ownership, budget and acceptance criteria would settle the classification.

## What our project hands over

After go-live in week 14, IT operations will take responsibility for monitoring, PostgreSQL backups, restarts and routine security maintenance on the gicitc.com VPS.

The operations team will receive deployment instructions, environment configuration guidance, a maintenance runbook, backup and recovery procedures, and access to monitoring tools.

The project team will also provide user documentation and support procedures so instructors can run quizzes and administrators can manage accounts, password resets and technical issues.
